# ❄️ Frost Night Factory - AI Context

**Frost Night Factory** is an autonomous AI agent system that generates production-ready Next.js applications from natural language descriptions. It orchestrates multiple AI models (Claude, Gemini, DeepSeek, Groq, Kimi, Perplexity) through a structured pipeline: research → planning → coding → SQL → testing → deployment.

### Backend
- **Database:** Supabase (PostgreSQL)
- **API:** Next.js API Routes (`app/api/`)
- **Auth:** Supabase Auth
- **Storage:** Supabase Storage

### Deployment
- **Hosting:** Vercel
- **Database:** Supabase Cloud

### AI Infrastructure
- **Models:** Claude Sonnet 4.5, Gemini 1.5 Flash, DeepSeek V3.2, Groq Llama 3.3, Kimi K2, Perplexity Sonar Pro
- **Caching:** Semantic cache (99% threshold, file-path keys)
- **Cost Tracking:** Per-pipeline, per-step token/cost tracking

## 📊 Database Schema (Key Tables)

```sql
-- Core Pipeline System
pipelines (
  id UUID PRIMARY KEY,
  name TEXT,
  initial_prompt TEXT,
  status TEXT,              -- 'pending' | 'running' | 'completed' | 'failed'
  current_phase TEXT,       -- 'research' | 'planner' | 'coder' | 'sql' | 'tester'
  total_ai_cost_cents INT,
  created_at TIMESTAMPTZ
)

pipeline_steps (
  id UUID PRIMARY KEY,
  pipeline_id UUID REFERENCES pipelines(id),
  name TEXT,                -- 'research' | 'planner' | 'coder' | 'sql' | 'tester'
  status TEXT,
  input JSONB,
  output JSONB,
  ai_cost_cents INT,
  tokens_in INT,
  tokens_out INT
)

-- AI Operations
ai_calls (
  id BIGSERIAL PRIMARY KEY,
  pipeline_id UUID,
  model TEXT,
  role TEXT,               -- 'PLANNER' | 'CODER' | 'FIXER' | 'REVIEWER'
  tokens_in INT,
  tokens_out INT,
  cost_cents INT
)

semantic_cache (
  cache_key TEXT,
  file_path TEXT,          -- NEW: Prevents cross-file contamination
  file_type TEXT,          -- 'route' | 'component' | 'page' | 'lib'
  prompt TEXT,
  response TEXT,
  similarity FLOAT         -- 99% threshold for strict matching
)

-- Error Management
error_patterns (
  id BIGSERIAL PRIMARY KEY,
  error_signature TEXT,
  solution TEXT,
  success_count INT
)

agent_memory (
  id BIGSERIAL PRIMARY KEY,
  error_signature TEXT,
  solution TEXT,
  reflection TEXT,
  success_count INT
)
```

## 📝 Pipeline Flow

```
1. RESEARCH → Perplexity/Kimi research queries
2. PLANNER → DeepSeek creates file structure plan
3. SCAFFOLDER → Creates empty files + injects Golden Components
4. CODER → Claude generates code (one file at a time, V7.5 mode)
5. SQL → Database migrations (if needed)
6. TESTER → TypeScript + ESLint validation, build simulation
7. PUBLISHER → Git push, Vercel deployment
```

## 🔒 Security & Best Practices

- **Sandbox:** All pipelines run in isolated `workspace/sandbox/` directories
- **Fortress Guard:** Critical files (tsconfig.json, package.json) protected from AI modification
- **Validation Gates:** 4-layer pre-testing validation (AST, Types, Build, RLS)
- **Error Handling:** Circuit breaker prevents infinite retry loops
- **Cost Controls:** Per-pipeline budgets, model routing based on complexity
